A full RAG (Retrieval-Augmented Generation) system with AI Chatbot built using n8n. This project automates document ingestion from Google Drive, processes and transforms data into embeddings using HuggingFace, stores them in Pinecone, and enables intelligent question-answering through an AI Agent powered by an LLM.

Overview This project demonstrates how to build an end-to-end RAG pipeline combined with a chatbot using n8n workflows. It enables automatic knowledge base updates and context-aware responses.

Features

Automated data ingestion from Google Drive Text processing and chunking Embedding generation (HuggingFace) Vector storage (Pinecone) AI-powered chatbot with contextual responses Modular and scalable workflow

Tech Stack

n8n (workflow automation) HuggingFace (embeddings) Pinecone (vector database) OpenRouter / LLM APIs

Use Cases

Document-based Q&A systems Knowledge base assistants Customer support automation
